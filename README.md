# simulation_proie_predateur
Premier projet basé sur de simples proies et prédateurs qui se nourrissent, se reproduisent et meurent.

### Origine du projet

J'ai commencé ce simulateur au début de mon semestre de M1 Bioinformatique, avant de travailler sur mon projet universitaire de bioinformatique et de Machine Learning hébergé sur GitLab.

L'objectif initial était de mettre en pratique mes connaissances en Python, notamment la programmation orientée objet, l'algorithmique, la manipulation de fichiers et la visualisation de données.

Depuis, les enseignements de mon master et mon projet universitaire m'ont permis d'acquérir de nouvelles méthodes de programmation, d'organisation du code et de traitement de données scientifiques.

Je souhaite désormais réinvestir ces compétences pour améliorer progressivement ce simulateur.

### Évolutions envisagées

- **Gestion des arguments :** utiliser `sys.argv`, puis éventuellement `argparse`, pour paramétrer la simulation directement depuis le terminal.
- **Organisation des résultats :** utiliser `pathlib.Path` pour gérer les chemins et créer un répertoire dédié aux fichiers de sortie.
- **Export des données :** enregistrer les résultats au format CSV pour faciliter leur analyse.
- **Qualité du code :** améliorer les commentaires, la structure des fonctions et la gestion des erreurs.
- **Machine Learning :** étudier la possibilité de développer un modèle capable de réguler automatiquement les populations de prédateurs afin de rechercher un équilibre durable de l'écosystème.

L'objectif à terme est de comparer une régulation manuelle à une régulation automatisée, en analysant leurs effets sur l'évolution des populations.
